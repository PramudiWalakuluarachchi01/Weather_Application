# Weather App 🌤️

![Flutter](https://img.shields.io/badge/Flutter-02569B?style=for-the-badge&logo=flutter&logoColor=white)
![Dart](https://img.shields.io/badge/Dart-0175C2?style=for-the-badge&logo=dart&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)

A Flutter mobile application that provides real-time weather information and hourly forecasts using the [OpenWeather API](https://openweathermap.org/api). The app displays temperature, sky conditions, humidity, wind speed, and atmospheric pressure in a clean and responsive UI.

---

## Features

- 🌡️ Current weather conditions for a selected city  
- ⏱️ Hourly weather forecast  
- 💧 Displays humidity, wind speed, and atmospheric pressure  
- 🔄 Refresh button to update weather data  
- ✨ Clean, modern, and responsive UI using Material Design
